# Bocetos de diseño

Copia local, solo como documentación, de los bocetos HTML que se usaron para acordar el diseño de cada pantalla antes de implementarla en código. No son parte de la app — son mockups estáticos (HTML/CSS puro, sin lógica) para revisar visualmente colores, tipografía y layout.

Cada archivo se puede abrir directo en el navegador. Ordenados por fecha de creación:

| Archivo | Contenido |
|---|---|
| `01-estructura-elisur-san-borja.html` | Primer boceto de arquitectura/estructura general del proyecto ELISUR (San Borja) |
| `02-paletas-de-color.html` | Opciones de paleta de color evaluadas antes de fijar verde+coral |
| `03-alternativas-de-navegacion.html` | Opciones de navegación principal evaluadas |
| `04-reorganizacion-app-vecinos.html` | Boceto de la reorganización a 4 pestañas (Inicio, Servicios, Comunidad, Perfil) |
| `05-rediseno-inicio.html` | Rediseño visual de la pantalla de Inicio |
| `06-muro-de-comunidad.html` | Rediseño de Comunidad como muro social |
| `07-rediseno-perfil.html` | Rediseño de Mi perfil |
| `08-rediseno-servicios.html` | Rediseño del catálogo de Servicios |
| `09-rediseno-guia-de-negocios.html` | Rediseño de las guías de listado (negocios/restaurantes/productos/supermarket) |
| `10-fichas-por-rubro.html` | Los 5 arquetipos de ficha de negocio (menú, catálogo, servicios, categorías, ofertas) |
| `11-rediseno-buscar.html` | Rediseño de la pantalla de Buscar |
| `12-rediseno-notificaciones.html` | Bandeja y ajustes de Notificaciones |
| `13-boceto-login.html` | Flujo de acceso (teléfono + código + perfil) |
| `14-panel-admin-general.html` | Panel administrador — Login, Dashboard, Negocios, Mi negocio, Avisos (visión general de los 3 roles iniciales) |
| `15-panel-admin-detalle-validacion.html` | Panel administrador — Distritos/comunidades, Nuevo negocio completo, Cola de validación, Cuentas, Mis avisos con rechazo |
| `16-panel-admin-modulos-restantes.html` | Panel administrador — Cambiar contraseña, Categorías, Publicidad, Historial de validaciones, Horario, Fotos, Ofertas, Estado del negocio, Nuevo aviso, Novedades |

Ver `docs/tecnica/07-panel-administrador.md` para el detalle de roles, campos y flujo de validación detrás de estos 3 últimos bocetos.

Estos bocetos también quedan publicados como Artifacts en la cuenta de Claude (con comentarios y versión "viva"); esta carpeta es solo la copia congelada para tenerla versionada junto con el código.
