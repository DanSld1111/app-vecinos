# Documentos legales — estado

- [`terminos-y-condiciones.md`](terminos-y-condiciones.md) — **borrador**
- [`politica-de-privacidad.md`](politica-de-privacidad.md) — **borrador**

Ambos son un punto de partida redactado a partir de lo que la aplicación **realmente hace hoy**
(qué datos pide, qué roles existen, qué está marcado "Próximamente") — no plantillas genéricas
copiadas de internet. Sirven para que un abogado especializado en protección de datos y derecho
del consumidor peruano los revise, corrija y complete antes de publicarlos.

**No se deben publicar tal cual.** Cada archivo tiene sus propios puntos marcados
`[ASÍ, entre corchetes]` donde falta información real de la empresa (razón social, RUC,
domicilio, correo de contacto real) o una decisión legal que no corresponde tomar sin asesoría
(límite de responsabilidad, edad mínima, base legal de cada tratamiento de datos según la Ley
N.° 29733).

Si la app cambia de forma relevante para estos documentos (se agrega geolocalización real,
notificaciones push con token de dispositivo, el módulo de pagos, etc.), hay que volver a
revisarlos — no son un documento que se escribe una vez y queda igual para siempre.
