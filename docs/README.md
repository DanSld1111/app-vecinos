# Documentación — proyecto ELISUR (nombre provisional)

Este es el índice de la documentación del proyecto. Está dividida en dos públicos porque no leen lo mismo ni necesitan lo mismo.

## `cliente/` — sin lenguaje técnico

Para el propietario del negocio, socios, junta vecinal, municipalidad y negocios afiliados. Describe qué hace la app y qué beneficio entrega, nunca cómo está construida.

## `tecnica/` — para el equipo de desarrollo

Arquitectura, stack, estructura del código, modelo de datos, contrato de API, guía de desarrollo y despliegue. Precisión sobre brevedad: nombres reales de archivos y rutas.

## `decisiones/` — registro histórico

Una decisión de arquitectura por archivo, con contexto, alternativas descartadas y consecuencias. Ver plantilla en `docs/tecnica/06-guia-de-desarrollo.md`.

## `diseno/` — bocetos

Copia congelada (HTML estático, sin lógica) de los bocetos usados para acordar cada pantalla antes de implementarla. Solo documentación visual, no código de la app.
